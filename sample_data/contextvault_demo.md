# Project Atlas Brief

Project Atlas is a small internal knowledge-search pilot. Ananya Rao is the project lead.

The pilot launch is scheduled for 18 November 2026. The only open delivery risk is that the dependency security review is not complete.

The team decided that source documents, embeddings, and generated answers must remain on the user's computer. Every answer must expose the supporting source passage so a person can verify it.

Success means a user can upload a source, retrieve it through keyword or semantic similarity, and receive a citation-backed answer in under ninety seconds on the target laptop.
